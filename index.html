只看汽车业务 来看看 $TSLA 近期动态。

1. Cybercab 无人驾驶出租车持续推进

特斯拉正在推进 Cybercab（无人驾驶出租车）项目。

这是一款没有方向盘和踏板的纯电自动驾驶车型，目标是成为未来 Robotaxi 车队的一部分。特斯拉已经开始在美国部分城市测试 Robotaxi 服务，并扩大运营范围。

对于电动车爱好者来说，Cybercab 最大的看点不是又一台车，而是它代表了一种新的汽车形态，甚至可以免驾照开车。

免驾照开车在全球范围内普及的话，汽车的潜在消费群体将会提高很多。

2:销量核心

目前特斯拉全球交付主力仍然是：
Model 3
Model Y
（我当时想买Model X 因为那个车门可以飞起来）
最新季度数据显示，车辆交付保持较高规模，其中 Model Y 和 Model 3 仍然贡献主要销量，近期财报也显示出货量大幅上涨。

这两款车已经成为全球电动车市场的重要代表，用我们行业的话来讲就是“龙头”。
Model 3：推动中型电动车普及
Model Y：将 SUV 电动车带入大众市场

3. FSD（完全自动驾驶能力）

特斯拉继续发展 FSD（Full Self-Driving）系统。

最新信息显示，FSD 用户规模持续扩大，同时 Robotaxi 也基于自动驾驶技术进行测试。

特斯拉的路线和很多传统车企不同：
传统车企：先造车 再加入智能功能
特斯拉：车辆硬件 + AI 软件 + 数据积累同步发展

而且特斯拉已经把FSD做成了按月付费的订阅制度，这又是特斯拉的一个稳定现金流收入。我认为这个改动是很合理，非买断制度才是促进企业不断更新软件的源动力。（毕竟一次性买断了，后续的服务其实在资本角度来说是没有保障的）

4. Optimus 人形机器人项目继续推进
除了汽车，特斯拉目前也在推进 Optimus 人形机器人，我们聊骑车就先不说这个了，MISA也没有骑过高达。

5. 能源业务增长
除了汽车本体，特斯拉能源业务也在发展，包括：

Megapack 储能系统
Powerwall 家庭储能

特斯拉在电池上的技术仍然是断档领先。

最新季度数据显示，储能产品部署量继续增长。
对于新能源爱好者来说，这部分很重要，因为未来能源生态可能不仅是：
买一辆电动车

而是：
太阳能 储能 家庭用电 电动车 智能能源管理

比如它已经不只是推出新车型，而是在尝试重新定义汽车是什么。

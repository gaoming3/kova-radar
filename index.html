🚨 这就是股市此刻正在崩盘的原因

如果你仍然认为市场是跟着头条新闻交易的，你必须仔细读完这篇。

因为那样的市场已经不复存在。

你此刻正在看到的并不是正常的价格走势。

这不是中期选举结果，那已经被市场消化。
这不是AI的终结。
而且这绝对不是AI禁令。

大多数人完全没有意识到正在发生什么。

而等到一切变得显而易见时，损害已经造成。

这轮走势并不是今天才开始的。
它已经在表面之下悄悄酝酿了数周。

而现在它正在加速。

真相是：

一场突如其来的情绪转变冲击了一个充斥着借来的钱的市场。

而当借来的钱遇上下跌的价格，价格就会跟着被迫卖出者走。

这正是今天发生的事情。

而这和已经发生在以下资产上的断裂是同一个：
→ 纳斯达克 −4.6%
→ 芯片指数 −9.8%
→ $NVDA 下跌7.6%
→ $BTC 下跌5.6%

标普500指数在一个上午内蒸发超过2万亿美元。

最初那个“AI没有规则”的故事已经破灭。

AI交易建立在两个理念之上：
→ 华盛顿不会挡AI的路
→ AI支出永远不会停止

这个故事在这一消息落地的那一刻就死了：
→ 一名众议院民主党人：“第1天”就暂停AI
→ 呼吁“禁止人工超级智能”
→ 一项禁令法案：最高可判20年监禁
→ 一名当选参议员：“我不为数据中心工作。”
→ 在21场州长选举中，暂停数据中心获得支持

从那一刻起，AI领域里每一美元借来的钱都变成了一个十足的陷阱。

不是在财报里。
而是在保证金账户里，这才是真正重要的。

保证金债务。

解释一切的那个指标。

9月以美国股票为抵押的借款达1.48万亿美元，接近6月创下的1.5万亿美元纪录。

一旦被迫抛售压倒真正的买家，价格就不再对新闻做出反应。

它对追加保证金通知、风险限额和强制平仓做出反应。

大型基金现在可能被迫出局。

他们并不是在猜测方向。

他们在做他们在每一个杠杆市场中都会做的事：
1⃣ 价格因AI禁令担忧而下跌
2⃣ 借来的钱触及上限
3⃣ 贷方要求现金
4⃣ 基金抛售他们的赢家
5⃣ 循环往复

这不是对AI的定论。

这是一场技术性的甩卖。

一条头条新闻刚刚袭来：
→ $AMD 下跌14.6%
→ 美光 −12.9%
→ 博通 −7.9%
→ 标普500指数 −3.4%

全部恰恰在同一时间发生。

这是一条头条新闻引发的4场崩盘。

那不是自由市场。

那是戴着AI禁令面具的追加保证金通知。

禁令不会发生。恐惧是真实的，但禁令会把AI竞赛拱手让给中国。

你想忽视它也可以，但别假装你没被警告过。

人类历史上最大的科技革命并没有在今天结束。把眼光放长远。保持冷静。

大多数人会把责任归咎于AI禁令的言论。分享这篇，让他们看到抛售背后借来的钱。

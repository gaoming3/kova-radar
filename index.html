一涨就想追，一跌就想割。

挂好的卖单，临到头又忍不住改个更高的价，然后眼睁睁看它砸下去。问题常常不在看不懂，而在看得太多。

mop 是一个开源的命令行行情看板。它不帮你下单，也不教你买卖，只把行情收成一张安静的表。
打开电脑自带的终端，运行之后上面是大盘和市场涨跌家数，下面是你的自选。

没有广告，没有推荐，没有你可能还想看。打开是数字，关掉就没有了。

仓库：https://t.co/raw8CDxYDU

打开窗口能看到现价、涨跌额、涨跌幅，开盘、当日最高最低，成交量、市盈率、股息、市值，还有52周最高和最低。
数据来自 Yahoo Finance，不用注册，也不用申请接口。默认大约5分钟刷新一次，不是逐笔行情。

美股直接写代码，如 $AAPL 。港股多半要带后缀，如 https://t.co/mqVTfKJypS。A股不是主场，别当日常交易软件用。

加自选按 +，删自选按 -，排序按 o，涨跌分开看按 g，筛选按 f，取消筛选按 F，离开按 q。

想少看杂讯，按 f 写一句条件即可。比如 last <= 5 只看价格不超过5的，changePercent > 0 && last < 5 只看在涨且价格还低的。列表会变短，不符合的不出现。这不是投资建议，只是事先规定自己看什么。

先安装 Go，再在终端执行：

git clone https://t.co/raw8CDxYDU
cd mop
go build ./cmd/mop
./mop

名单存在 ~/.moprc。内地访问 Yahoo 可能空白或很慢，先检查网络。

和常见工具差在哪。交易 App 能买能卖，但吵。浏览器自选不用安装，但要切来切去。mop 只负责安静地展示，并按你写好的条件过滤。

它没有K线，不能交易，也拦不住你改价。
看见和下单是分开的，这就是边界。

🚨 这就是为什么现在一切都在不停暴跌

如果你仍然认为市场是按新闻交易的，你必须仔细阅读这篇。

因为那样的市场已经不复存在。

你现在看到的不是正常的价格走势。

这不是“糟糕的一天”。
这不是一次财报不及预期。
而且这绝对不是散户在抛售。

大多数人完全没有意识到正在发生什么。

而等到这一切变得明显时，损害已经造成。

这波走势不是今天才开始的。
它已经在表面之下悄悄酝酿了两天。

而现在它正在加速。

真相是：

在有报道称美国正准备在伊朗展开大规模作战的数小时后，杠杆开始平仓。

而当杠杆平仓时，价格不再跟随买家，而是跟随强制抛售。

这正是今天发生的事。

而这与已经发生在以下市场的断裂是同一个：
→ 纳斯达克 −4%
→ 芯片股 −9%
→ $BTC −5%，跌破$77,000
→ 油价重回$90上方

大约2万亿美元的股票市值在一个上午内蒸发。

最初的中期选举反弹逻辑已经破裂。

昨天的反弹建立在两个想法之上：
→ 民主党控制的国会让新的打击更难实施
→ 伊朗协议的希望使油价下跌8%

华盛顿加上以下这些的那一刻，这两个想法都破灭了：
→ 华尔街日报：官员敦促特朗普重启大规模打击
→ 一些人希望他先发动打击，再寻求和平
→ Axios：军方正在完成准备工作
→ 更多美国军事资产被派往该地区
→ 一名前顾问：特朗普“不想第二次看起来像个失败者”

从那一刻起，每一笔杠杆押注都变成了一笔实实在在的负债。

不是在头条新闻里。
而是在保证金账户里，而那才是真正重要的。

加密货币多头爆仓。

解释一切的指标。

60分钟内，4亿美元的杠杆多头被清算殆尽。

一旦强制抛售压倒真实买家，价格就不再对新闻作出反应。

它对追加保证金通知、止损和强制平仓作出反应。

交易所现在可以替你平仓。

它们不是在猜方向。

它们在做它们在每个杠杆市场都会做的事：
1⃣ 价格跌入一堵止损墙
2⃣ 保证金耗尽
3⃣ 交易所强制卖出
4⃣ 这笔卖单撞上下一堵墙
5⃣ 重复

这不是“恐慌”。

这是一条强制抛售链。

仅一个上午之内就刚刚出现了：
→ 美光 −13%
→ 英伟达 −7%
→ $ETH 下跌6%
→ VIX恐慌指数上涨超过40%

全都恰恰发生在同一时间。

这是同一个交易时段承受的4项索求。

那不是自由市场。

那是戴着伊朗头条面具的追加保证金通知。

你想忽视就忽视，但别假装你没被警告过。

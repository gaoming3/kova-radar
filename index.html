Intel 第三季桌機 CPU 市占回升至70%，AMD 跌破三成，但背後是供貨與市場萎縮

Intel（ $INTC）在桌機 CPU 市場意外反攻，拿回不少先前被 AMD（ $AMD）搶走的市占。不過這波回升，可能更多來自供貨調度與電競 PC 市場疲弱，而不是處理器競爭力突然逆轉。

依 Mercury Research 公布的2026年第三季數據，Intel 桌機 x86 CPU 出貨市占從前一季的65.1%升到70.1%，AMD 則從34.9%降到29.9%，一來一往約5個百分點。這個結果相當出人意料，因為今年8月時，Intel 整體 x86 CPU 市占才剛跌到1995年以來的低點，AMD 則在多個領域持續擴張。

Mercury Research 坦言確切原因還不清楚，但推測 Intel 在行動 CPU 需求轉弱後，把更多處理器供貨轉向桌機市場。桌機 CPU 需求通常在第三季回溫，Intel 在2026年上半年對桌機供貨不足，這次正好搭上季節性回升；AMD 則沒能抓住同一波需求。

另一個可能原因是 AMD 對高階電競市場的曝險較高。即使 Ryzen X3D 處理器在遊戲效能上仍有明顯優勢，電競 GPU 供貨吃緊壓抑了電競 PC 需求，對 AMD 衝擊較大。DRAM 價格上漲也讓情況更糟，Intel 自己的第三季財報就承認，記憶體等零組件成本上升拖累了消費端需求；儘管桌機出貨市占上升，Intel 客戶端運算與實體 AI 事業群營收仍年減5%。

整體市場其實在萎縮。
Jon Peddie Research（JPR）11月13日公布的第三季數據顯示，全球客戶端 CPU 出貨量季減3.4%、年減6.5%，只有6,080萬顆。其中桌機 CPU 出貨年減13%，筆電處理器則小幅減少4%。JPR 認為部分原因是 DIY 電競市場需求疲弱，消費者為了躲避預期中的記憶體與 SSD 漲價，把購買提前到2025年底。

伺服器 CPU 則走出相反的方向，出貨量升到813萬顆，前一季為783萬顆，一年前為659萬顆，而且 AMD 持續擴大市占。JPR 總裁 Jon Peddie 預期，PC 市場的困境至少會延續到2027年上半年。換句話說，Intel 的桌機市占回升，是發生在一個正在縮小的市場裡，並不代表消費性 CPU 需求全面復甦。

AMD 的重心也已明顯轉向資料中心。最新一季資料中心營收創下85億美元新高，年增97%；執行長蘇姿丰日前直言「我們是資料中心優先的公司」。第三季 AMD 伺服器 CPU 出貨市占也從34.5%升到35.5%，整體競爭地位依然穩固。
